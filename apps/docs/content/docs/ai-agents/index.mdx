These prompts help a coding agent integrate egy-pay into an existing Node.js application. Paste the matching prompt at the application root, or save it in that tool’s project instructions.

Each prompt directs a coding agent to install the single `egy-pay` npm package, inspect its types, connect the host application's existing database, and preserve the payment verification rules.

- [Codex setup prompt](/docs/ai-agents/codex)
- [Claude Code setup prompt](/docs/ai-agents/claude-code)
- [OpenCode setup prompt](/docs/ai-agents/opencode)

Every prompt carries the same product rules: customer claims are unverified, privileged verification requires host authorization, and fulfillment starts only after confirmed payment.
